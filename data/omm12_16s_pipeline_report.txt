OMM12 16S rRNA gene phylogeny -- pipeline report
============================================================

Method: one representative 16S rRNA gene copy per genome (longest
annotated copy), aligned with a custom Gotoh affine-gap-penalty
center-star multiple alignment (medoid-sequence-anchored), pairwise
distances corrected with the Jukes-Cantor (1969) substitution model,
tree built by Neighbor-Joining (Saitou & Nei 1987), support from
200 bootstrap replicates (column resampling with replacement,
RNG seed 20260909 for reproducibility).

Alignment: 12 taxa x 1710 columns.
No external alignment/tree tools were available in this environment
(no internet access to install MAFFT/IQ-TREE/etc.) -- this is a from-
scratch pure-Python/numpy implementation. Each component (pairwise
aligner, JC correction, Neighbor-Joining) was unit-tested against
known-correct reference cases before being run on real data; see
nw_align.py, jc_distance.py and test_nj.py in build_omm12_16s_tree/
at the repo root (alongside extract_16s.py, build_msa.py, run_tree.py
and bootstrap.py, which run the full pipeline end to end).

This is a real single-locus (16S) molecular phylogeny with alignment,
a substitution model, and bootstrap support -- a genuine improvement
over a k-mer/UPGMA similarity sketch. It is NOT a whole-genome GBDP
tree (which would need many more loci / whole-genome distances) and,
like any single-gene tree, has limited power to resolve the deepest,
most ancient splits between very different phyla -- treat weakly
supported deep branches (~<70% bootstrap) with appropriate caution.
